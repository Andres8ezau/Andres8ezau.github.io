# Ciencia en el Extranjero

Sitio web para estudiantes de ciencias en México que buscan estancias y veranos de investigación en el extranjero.

## Estructura

- **Oportunidades** — Programas nacionales e internacionales (datos en `js/data.js`)
- **Blog** — Entradas y guías (`js/data.js` → `blog`)
- **Recursos** — Plantillas de CV, organizaciones y archivos (`js/data.js` → `resources`)

## Editar contenido

Abre `js/data.js` para agregar o modificar oportunidades, entradas de blog y recursos.

## Desarrollo local

Abre `index.html` en un navegador o usa un servidor local:

```bash
python -m http.server 8080
```

Luego visita `http://localhost:8080`.
